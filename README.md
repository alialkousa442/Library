# Library
# 📚 Personal Library App

A clean, modern, and responsive web application designed to help users track their personal reading lists. Built with vanilla JavaScript, dynamic DOM manipulation, and styled with a custom violet theme.

![Project Preview](https://via.placeholder.com/800x400.png?text=Library+App+Preview) *(يمكنك استبدال هذا الرابط برابط صورة لموقعك)*

---

## ✨ Features

* **Book Management:** Easily add new books with title, author, and page count.
* **Reading Status Toggle:** Toggle between "Read" and "Not Read" status dynamically.
* **Persistent Layout:** Uniform card dimensions and responsive alignment regardless of missing data fields.
* **Responsive Design:** Built with CSS Grid and Flexbox for seamless viewing on desktops and mobile devices.
* **Violet UI Theme:** Customized with a distinct and modern violet color palette.

---

## 🛠️ Built With

* **HTML5:** Semantic structure and dynamic dialog forms.
* **CSS3:** Custom styling utilizing CSS Grid, Flexbox, and CSS Variables.
* **JavaScript (ES6):** Object constructors, DOM manipulation, and state management.
